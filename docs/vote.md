# 2026년 11월 일정 투표

참여 주소: https://lucas-jang.github.io/vote/

Astro 정적 페이지 `src/pages/vote.astro`와 전용 CSS/클라이언트 스크립트를 사용한다. 기존 블로그 레이아웃과 메뉴는 수정하지 않는다. 로그인 없이 이름 또는 별명과 가능한 날짜를 입력한다. 이름과 날짜는 페이지 방문자에게 표시된다. 사이트 검색에 포함하지 않으며 검색 로봇에 noindex를 지정한다.

## 공유 저장

GitHub Pages는 서버를 실행하지 않으므로 별도 Sites API와 D1 데이터베이스에 투표를 저장한다. 브라우저 localStorage에는 256비트 무작위 수정 토큰과 미저장 초안만 저장한다. 다른 기기나 브라우저에서는 기존 투표 수정 권한이 이어지지 않는다. 이름이 같아도 다른 참여자일 수 있으므로 이름을 수정 권한으로 사용하지 않는다. 로그인 없는 방식이므로 브라우저 데이터를 지우거나 다른 브라우저를 사용한 동일인의 재투표까지 차단하지 않는다.

- API: `https://november-vote-api-lj.brinysnail26.chatgpt.site/api/votes`
- Sites 프로젝트: `appgprj_6adfe6430ed88191b8444cb951063388`
- API 구현과 migrations는 해당 Sites 소스 저장소에서 관리한다. 이전 비공개 시안과 별도 서비스다.
- GET: 전체 투표와 현재 토큰의 `ownId`를 반환한다. 토큰/소유자 해시는 반환하지 않는다.
- POST: 현재 토큰의 투표를 추가하거나 변경한다. 동일 토큰 재시도는 중복 투표를 만들지 않는다.
- DELETE: 현재 토큰의 투표만 삭제한다.
- 클라이언트는 `Authorization: Bearer <무작위 수정 토큰>`을 보낸다. 서버는 토큰의 SHA-256 해시만 DB에 저장한다.
- CORS는 `https://lucas-jang.github.io`만 허용한다. 로컬 API 실행 시에만 localhost/127.0.0.1:4321도 허용한다. API 키나 GitHub 토큰을 클라이언트에 넣지 않는다.
- 데이터는 조회할 때마다 서버에서 읽고, 화면이 보이는 동안 20초마다 갱신한다. 서버 연결 실패를 별도로 표시하며 브라우저 초안을 공유 투표로 간주하지 않는다.

## 상호작용

날짜는 복수 선택 가능한 기본 button이며 키보드 Tab/Enter/Space로 조작한다. `aria-pressed`와 체크 표시를 함께 제공한다. 주말 선택은 기존 선택을 유지하면서 토요일/일요일을 추가한다. 변경사항을 저장하기 전에는 집계에 반영하지 않는다. 미저장 변경은 복원하며 페이지를 떠날 때 경고한다. 삭제는 이름/일정 삭제 범위를 설명하는 dialog에서 확인한다.

모바일에서는 저장 버튼과 선택 수를 아래에 고정한다. 결과는 색 농도와 인원 숫자를 함께 표시하며 공동 1위를 모두 알려준다. 빈 투표에서 추천 날짜나 참여자를 만들지 않는다. 애니메이션은 reduced-motion 환경설정을 따른다.

## 확인

`node --test scripts/vote.test.mjs`, `npm run check`, `npm run build`.

로컬 API와 함께 확인할 때만 `PUBLIC_VOTE_API_URL=http://127.0.0.1:5173/api/votes`를 환경변수로 지정해 `npm run dev -- --host 127.0.0.1`을 실행한다. 프로덕션 빌드에는 이 환경변수를 설정하지 않는다. 기본 endpoint 변경은 `src/lib/vote-api.ts`에서 수행한다.
