# 진단 회식 초대장 · 2026년 11월

참여 주소: https://lucas-jang.github.io/vote/

모바일 한 화면 안에서 `초대장 → 이름 → 환영 → 달력 → 답장 완료`로 전환한다. 각 단계만 표시하며 문서와 내부 패널 모두 스크롤하지 않는다. 화면은 100dvh와 visualViewport 높이를 따라 조절하며 작은 화면/가상 키보드용 배치를 제공한다. 기존 블로그 메뉴와 레이아웃은 수정하지 않는다.

## 이름과 인사

전지원, 장원준, 송창훈은 “명단에도 있고, 마음에도 있습니다”라는 인사를 받는다. 다른 이름은 “명단엔 없어도, 빈자리는 있어요”로 환영한다. 모든 이름으로 투표할 수 있다. 명단 판정은 초대장 문구를 고르기 위한 것이며 본인 인증이나 접근 제한이 아니다. 이름은 NFC 정규화와 공백 정리를 거치며 textContent로 출력한다.

## 회신 마감

2026년 11월 6일 23:59:59 한국시간까지 저장·수정할 수 있다. 최초 마감 시점은 `2026-11-07T00:00:00+09:00`이다. 달력 아래에 초 단위 카운트다운과 마감일을 표시한다. 서버의 `serverTime`, `deadlineAt`, `closed`로 시계를 동기화하며 경과 시간은 performance.now()를 사용한다. 카운트다운을 스크린 리더에 매초 반복 공지하지 않는다.

서버는 POST/DELETE 양쪽에서 마감을 검사하고, 마감 후에는 `410`과 `code: VOTING_CLOSED`를 반환한다. GET과 모인 일정 조회는 계속 가능하다. API의 `lib/voting-window.mjs`와 프런트의 `src/lib/vote-model.mjs`에 같은 마감 시점을 유지한다. 서버가 최종 기준이다.

## 저장과 수정

GitHub Pages는 서버를 실행하지 않으므로 별도 Sites API와 D1에 투표를 저장한다.

- API: `https://november-vote-api-lj.brinysnail26.chatgpt.site/api/votes`
- Sites 프로젝트: `appgprj_6adfe6430ed88191b8444cb951063388`
- 서버 소스와 migrations는 해당 Sites 소스 저장소에서 관리한다.
- localStorage에는 256비트 무작위 수정 토큰과 미저장 초안만 보관한다. 서버에는 수정 토큰의 SHA-256 해시를 저장한다.
- GET은 전체 투표, 현재 토큰의 ownId, 서버 시각과 마감을 반환한다. 토큰/소유자 해시는 공개하지 않는다.
- POST는 같은 토큰의 투표를 추가하거나 갱신한다. 저장 재시도는 중복 투표를 만들지 않는다.
- DELETE는 현재 토큰의 투표만 삭제하는 기존 API로 남아 있으며 새 초대장 UI에는 삭제 기능이 없다.
- CORS는 `https://lucas-jang.github.io`를 허용한다. 로컬 API에서만 localhost/127.0.0.1:4321도 허용한다.

이름과 선택 날짜는 페이지 방문자에게 표시된다. 같은 브라우저에서 자신의 투표를 수정한다. 다른 기기나 브라우저로 수정 권한이 이어지지 않으며 브라우저 데이터를 지운 동일인의 재투표까지 차단하지는 않는다. 이름만으로 수정 권한을 부여하지 않는다.

미저장 초안을 자동 복원하고, 저장이 성공하면 접수된 답장을 보여준다. 완료 화면에서 다시 고르거나 모인 일정을 볼 수 있다. 연결 오류 시 선택을 유지하고 다시 연결할 수 있다. 모인 일정은 화면이 보이는 동안 20초마다 갱신하며 날짜별 수치와 최다 가능일(공동 1위 포함)을 표시한다. 빈 투표에 추천 날짜나 가짜 참여자를 만들지 않는다.

## 확인

`npm run test:vote`, `npm run check`, `npm run build`.

이름 세 가지/다른 이름, 한국시간 마감 직전·정각·직후, 카운트다운 단위를 단위 테스트한다. 모바일 320×568 및 390×844에서 초대장·이름·환영·달력·완료 화면의 넘침과 투표 수정 동작을 브라우저로 확인한다.

로컬 API와 함께 확인할 때만 `PUBLIC_VOTE_API_URL=http://127.0.0.1:5173/api/votes`로 `npm run dev -- --host 127.0.0.1`을 실행한다. 프로덕션 빌드에는 이 변수를 설정하지 않는다. 기본 endpoint는 `src/lib/vote-api.ts`에서 관리한다.
