## 검증과 한계

- 기술별 361개 정규화 시간 표본에서 두 사람의 신체 비율, 뼈 길이, 관절 연속성, 발·관절의 매트 관통과 비인접 몸통 중심부 관통을 검사했다.
- 기술별 순서 검사: 더블렉의 레벨 체인지·머리 바깥 위치·뒤발 회수, 삼각의 골반 지지와 회전, 암바의 착석 후 눕기, 오모플라타의 바깥손 지지, 보우앤애로우의 바지 그립 선행.
- `npm run bjj:render`로 기술당 6개 진행 위치를 4방향에서 렌더링한다. 총 120개 모델 자세를 비교한다. 이는 실제 모델 기하 검토이며 브라우저 WebGL 화면·터치 조작 검증을 대체하지 않는다.
- 더블렉은 14초, 나머지 네 기술은 16초로 천천히 시연한다. 표본 사이에는 뼈 길이를 유지하는 보간을 사용한다.
- 영상당 10개 프레임, 총 540개 프레임을 근거로 삼았다. 가려진 손가락, 의복 내부 접촉, 실제 힘과 인체 전체 충돌은 모델링하지 않았다. 수학적 통과가 실전 기술 정확성 인증을 뜻하지 않는다.
