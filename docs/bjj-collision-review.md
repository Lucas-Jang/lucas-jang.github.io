# 주짓수 신체 관통 수정

검토 순서: 삼각조르기, 더블렉, 마운트 암바, 오모플라타, 보우앤애로우.

## 기존 검사가 놓친 부분

기존 검사는 팔·다리의 중심선이 머리나 몸통의 중심부에 깊게 들어갔는지만 확인했다. 반지름을 포함하지 않았고, 목·다른 팔다리·손·발의 부피를 검사하지 않았다. 중심선이 검사에 통과해도 화면의 원통과 구체는 상대 몸을 뚫을 수 있었다. 각 팔다리의 경로도 따로 골라 서로 교차하는 조합을 허용했다.

삼각 잠금의 발목과 반대 무릎을 지나치게 가깝게 두었던 조건도 접촉을 관통으로 만들었다. 또 저장된 프레임 검사와 실제 재생 중 역운동학 보간이 달라 프레임 사이의 뒤집힘을 놓쳤다.

## 수정 방식

- 몸통·골반·목·머리를 회전한 타원체 및 캡슐로, 팔·다리를 실제 반지름의 캡슐로 검사한다. 손·발은 표시된 타원체와 같은 크기와 회전을 사용한다.
- 두 사람의 팔다리와 골반 위치를 함께 최적화한다. 몸을 통과하지 않는 경로를 우선하며, 뼈 길이는 해석적 두 관절 역운동학으로 고정한다. 매트 접지와 손목 그립도 제약에 포함한다.
- 삼각은 닫힌 잠금의 유효한 자세에서 역방향으로 경로를 구해, 충돌을 피한다며 마지막 잠금을 풀어 버리는 해를 방지한다. 잠금·골반 지지, 암바의 S마운트, 오모플라타의 손 지지 등 기존 기술 순서 검사도 유지한다.
- 프레임 사이의 급격한 관절·손발 이동을 제한한다. `sampleMotion`을 화면과 검사에서 함께 사용한다.
- 손·발 타원체의 대칭인 회전은 같은 표시 자세로 취급한다. 같은 모양인데도 보간 중 90도 옆으로 돌아 상대 팔을 스치는 문제를 막는다.
- 자신의 어깨·골반에 붙어 있는 상완·허벅지의 연결 부위만 인접 충돌에서 제외한다. 상대방의 신체에는 이 예외를 적용하지 않는다.

## 재검증

`npm run test:bjj`는 기술별 361개 저장 자세와 그 사이 1/4·1/2·3/4 위치를 검사한다. 기술당 1,441개, 총 7,205개 시점이다. 보수적인 충돌체의 관통 허용 오차는 6mm이며, 기존의 뼈 길이·관절 연속성·그립·삼각 잠금·기술 순서 검사를 약화하지 않는다.

`npm run bjj:render`는 실제 모델과 재생 코드를 사용해 네 방향의 자세 이미지를 만든다. 이는 브라우저의 WebGL 조명·그림자나 직접 드래그 조작을 검사하는 도구는 아니다. 옷깃·벨트·손가락 같은 세부 접촉과 실제 인체의 힘은 모델링하지 않는다.

2026-11-04 수정 결과: 삼각조르기·더블렉·마운트 암바·오모플라타·보우앤애로우 모두 1,441개 검사 시점에서 허용 오차를 넘는 충돌 0건. 중심선만 머리 밖에 있고 팔의 두께는 겹치는 경우, 몸통과 떨어진 두 팔다리가 교차하는 경우, 손·발의 대칭 회전 보간 오류를 재현하는 회귀 검사도 추가했다.

## 동작 다시 계산하기

브라우저와 일반 빌드에는 Python이 필요하지 않다. 오프라인 동작 재계산에만 NumPy와 SciPy를 사용한다.

```powershell
python -m pip install -r scripts/requirements-bjj-motion.txt
npm run bjj:bake -- triangle
npm run test:bjj
npm run bjj:render
```

`BJJ_PYTHON` 환경 변수로 Python 실행 경로를 지정할 수 있다. 초벌 계산은 `.astro`에만 저장하고, 부피 계산·프레임 사이 충돌·기술 순서 회귀 검사가 모두 통과한 뒤에만 공개 동작 데이터를 교체한다. 검사 실패 시 기존 공개 데이터는 보존한다.
